### 1. 主 JS 分包（首屏瘦身）
- 原 `App.tsx` `git mv` 为 `AppStage.tsx`（保留文件历史），新 `client/src/App.tsx` 为薄引导层：`React.lazy` 按需加载 AppStage/Admin，Suspense 显示 BootFallback；动态 chunk 拉取失败 12s 后出现「重新加载」按钮（attempt state 重建 lazy 节点，真实重新发起 import，非 location.reload）

### 2. 弱网降级链：Socket → REST → outbox → 重连去重
- 新增 `client/src/application/outbox.ts`（纯函数内核 + localStorage 适配，key `da_outbox_v1`）：eventId 入队幂等、上限 50 条淘汰最旧、flush 并发复用同一 promise、顺序回放、服务端 duplicate 视为送达出队、失败计数保留、maxTries=20 死信丢弃、坏 JSON 安全降级空队列；12 项单测
- `client/src/application/sendInteraction.ts`：`SendInteractionResult` 携带 `eventId/payload`；REST 彻底失败时 AppStage 据此入队并 toast「已暂存，联网后自动送达」
- 触发回放：socket `connect`、window `online`、`visibilitychange` 回前台、顶栏「📶 N 条消息等待联网送达」按钮手动重试；送达后刷新时间线
- 契约验证 `scripts/verify-offline-replay.mjs`：真实启动 express（内存 SQLite），5 项——离线期间零落库、重连顺序回放且同 eventId 合并、二次回放 duplicate 出队、新事件不被旧队列污染、坏载荷不阻塞好条目

### 3. 资产失败回退（不白屏）
- 己方舞台两级回退：首选形象加载失败 → 自动加载 DEFAULT_AVATAR（toast 说明）→ 仍失败显示 `.stage-error` 占位卡片（🌧️ + 重新加载按钮）；对方模型加载失败仅 toast + 收起加载态，己方舞台与互动不受影响
