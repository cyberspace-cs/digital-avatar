## 1. 执行范围与边界

### 1.1 本阶段负责（豆包）

- Tao 动作参考图生成（wave 5帧 + heart 5帧，共10张）
- Tao 合并动作板（2行×5列，1张）
- Jing 动作参考图整理（用户已提供，归档到项目目录）
- Jing 合并动作板归档
- 动作图质量自检和迭代
- 生成给代码端（Trae）的资产交付说明

### 1.2 本阶段不负责

- 不写任何业务代码（由 workbuddy / trae 负责）
- 不生成 Live2D MOC3 / motion3 / physics3 运行时文件
- 不修改 `client/public/models/` 下的旧模型
- 不恢复等级/任务/火花系统
- 不把 PNG 动作图接入运行时播放逻辑

### 1.3 禁止项（契约硬约束）

| 禁止项 | 原因 |
|--------|------|
| 不得把 PNG 动作图直接当作 Live2D 运行时资产 | 契约第4节：动作板只用于设计、沟通和验收；正式运行时必须用 Cubism 参数和 motion3 |
| 不得删除旧模型（Hiyori/Haru/Natori/Chitose） | 契约第2节：作为过渡模型保留 |
| 不得恢复等级/任务/火花系统 | 契约第2节：已删除，关系价值由共同经历表达 |
| 不得使用 TapBody 下标取模实现动作语义 | 契约第7节：未知动作按语义降级，禁止按下标取模 |
| 不得伪造生产 MOC3 | 实施计划 Task 5：正式资产到位前只用占位 fixture |

## 3. 图片技术规格

### 3.1 单独动作帧

| 参数 | 规格 |
|------|------|
| 格式 | PNG（带 alpha 透明通道） |
| 画布 | 正方形，1024×1024 px |
| 背景 | 完全透明（alpha=0），无地面投影、无背景色 |
| 角色高度 | 同一角色10帧内完全统一；男女有差异：Jing 约占画布高度 82%～85%，Tao 约占 88%～91%（男生比女生高大） |
| 脚底基线 | 同一角色所有帧在同一水平线上（距底部约 5%）；男女合并对比时脚底基线对齐，男生整体更高 |
| 肩宽差异 | Tao 肩宽略宽于 Jing，体现男性体型；均为 Q 版圆润比例 |
| 人物位置 | 水平居中，左右边距对称 |
| 色彩模式 | RGB，8bit/通道 |
| 无文字 | 帧内无文件名、无水印、无标注 |
| 无水印 | 不得保留"AI生成"等平台水印 |

### 3.2 合并动作板

| 参数 | 规格 |
|------|------|
| 格式 | PNG |
| 画布 | 横向，宽:高 = 5:2（例如 2560×1024） |
| 布局 | 2行×5列，上排 wave，下排 heart |
| 间距 | 单元格间距统一，角色在各自单元格内居中 |
| 标注 | 单元格下方可标注帧序号（如 `tao_wave_01`），字体统一 |
| 背景 | 浅灰白（#F5F5F5），便于查看透明边缘 |

## 4. 生成工具与流程

### 4.1 工具选择

| 步骤 | 工具 | 说明 |
|------|------|------|
| 单帧生成 | `image_gen` | 文生图，基于描述词 + 参考图 |
| 参考图一致性 | `image_edit` | 以基准立绘或上一帧为参考，保持角色身份一致 |
| 合并动作板 | `image_gen` 或脚本拼接 | 生成带标注的2行×5列合并图 |
| 透明背景处理 | 后处理检查 | 确认 alpha 通道，必要时去底 |

### 4.2 生成流程（每轮迭代）

```
1. 确认基准立绘
   └─ 用 Tao.png 作为角色身份参考
   └─ 确认造型、比例、画风与契约一致

2. 逐帧生成（wave 01→05，heart 01→05）
   ├─ 每帧使用统一的角色基准描述词
   ├─ 叠加该帧的动作描述
   ├─ 使用基准立绘作为 image_reference 保持身份一致
   └─ 生成后立即检查：身份一致？透明背景？无水印？

3. 批次自检
   ├─ 10帧并排比对：角色身高/基线/位置是否统一
   ├─ 动作节拍：待机→准备→峰值→回落→待机 是否连贯
   ├─ Tao heart 是否为单手 finger-heart（非双手比心）
   └─ 不合格帧标记，重新生成

4. 合并动作板
   └─ 2行×5列拼接，上 wave 下 heart，标注帧名

5. 交付归档
   ├─ 10张单独帧 → docs/assets/action-boards/tao/
   ├─ 1张合并板 → docs/assets/action-boards/tao_action_board.png
   └─ Jing 已有动作图 → 归档到 docs/assets/action-boards/jing/

6. 人工确认
   └─ 用户审核 → 通过则锁定 → 不通过则迭代重生成
```

### 4.3 参考图使用策略

为保证10帧角色身份一致：

- **主参考**：Tao 基准立绘（`docs/assets/reference/Tao.png`）
- **辅助参考**：已确认的前一帧（例如生成 wave_03 时参考 wave_02）
- **禁止**：每帧从零生成（会导致身份漂移）

## 6. 质量检查清单

### 6.1 单帧检查（每张必过）

- [ ] 文件格式为 PNG，带 alpha 通道
- [ ] 背景完全透明，无残留底色、无地面投影
- [ ] 画布为正方形，尺寸 1024×1024
- [ ] 角色完整全身，无裁切
- [ ] 角色水平居中，脚底基线位置正确
- [ ] 无文字、无水印、无"AI生成"标识
- [ ] Tao 造型正确：黑短发、白衬衫、条纹领带、黑长裤、白运动鞋
- [ ] 无背包、无背包带、无多余配饰
- [ ] 手部无畸形、无多手指
- [ ] 画风为日系清新平涂，低饱和配色

### 6.2 批次检查（10帧一起）

- [ ] 10帧角色身高完全一致
- [ ] 10帧脚底基线在同一水平线
- [ ] 10帧角色水平位置一致
- [ ] 10帧发型、发色、服装颜色完全一致
- [ ] wave 5帧动作节拍连贯：待机→抬手→挥手→保持→回落
- [ ] heart 5帧动作节拍连贯：待机→抬手→比心→保持→回落
- [ ] heart 为单手 finger-heart，另一只手扶领带（非双手比心）
- [ ] wave 动作克制自然，肩部高度，略微前倾（不夸张）
- [ ] 帧间过渡自然，无跳变

### 6.3 合并板检查

- [ ] 2行×5列布局正确
- [ ] 上排为 wave_01~05，下排为 heart_01~05
- [ ] 帧序号标注正确、字体统一
- [ ] 所有角色在单元格内居中
- [ ] 与女主动作板结构对应

### 6.4 契约合规检查

- [ ] 所有文件在 `docs/assets/action-boards/` 下，未放入 `client/public/models/`
- [ ] 未修改任何代码文件
- [ ] 未删除任何旧模型
- [ ] 文件名符合 `tao_wave_XX.png` / `tao_heart_XX.png` 规范
- [ ] 动作板仅作设计参考，未接入运行时

## 7. 迭代与确认机制

### 7.1 迭代轮次

| 轮次 | 产出 | 确认点 |
|------|------|--------|
| 第1轮 | Tao 基准立绘确认 | 身份/造型/画风是否正确 |
| 第2轮 | wave 5帧 + 自检 | 动作节拍/身份一致性/透明背景 |
| 第3轮 | heart 5帧 + 自检 | 单手finger-heart/动作节拍/身份一致性 |
| 第4轮 | 合并动作板 | 布局/标注/整体效果 |
| 最终 | 全部归档 + 交付说明 | 锁定资产，生成给Trae的代码提示词 |

### 7.2 不合格处理

- 单帧不合格：重新生成该帧，不影响其他已确认帧
- 身份漂移（多帧角色不一致）：以基准立绘为参考，批量重新生成
- 动作语义错误（如heart变成双手比心）：调整描述词，重新生成该动作全部5帧
- 透明背景失败：后处理去底，或重新生成

### 8.2 动作语义映射（给代码端）

| actionId | 帧前缀 | 帧数 | 播放顺序 | 说明 |
|----------|--------|------|----------|------|
| `wave` | `tao_wave_` | 5 | 01→02→03→04→05 | 肩部轻挥，克制自然 |
| `heart` | `tao_heart_` | 5 | 01→02→03→04→05 | 单手finger-heart |

### 8.3 代码端注意事项（写入交付说明）

- 这些 PNG 是**设计参考板**，用于 Live2D 动作制作的姿势参照
- **不得**直接将 PNG 序列帧作为运行时动画播放
- 运行时必须使用 Cubism 5 的 `motion3.json`，由动作师参照这些关键帧制作
- 动作语义通过 `actionId` 标识，禁止用 TapBody 下标取模
- 未知动作按降级链处理：精确动作→同语义→通用反应→待机+气泡→只保留事件

## 9. 风险与缓解

| 风险 | 概率 | 影响 | 缓解措施 |
|------|------|------|----------|
| AI 生成角色身份漂移 | 高 | 动作板无法作为验收基准 | 每帧用基准立绘作参考，批次并排比对，不合格重生 |
| 单手 finger-heart 手势画错 | 中 | heart 动作语义错误 | 描述词明确"拇指食指交叉"，多轮生成筛选，必要时用 image_edit 修正 |
| 透明背景生成不稳定 | 中 | 违反契约透明背景要求 | 生成后检查 alpha 通道，后处理去底 |
| 10帧基线/高度不统一 | 中 | 动作节拍失效 | 统一画布尺寸和描述词，生成后逐张比对基线 |
| 动作板被误当作运行时资产 | 低 | 违反契约 | 目录放 docs/assets/，交付说明明确标注"设计参考，非运行时" |
| wave_04 出现背包带（已有问题） | 低 | 造型错误 | 负面提示词加入"背包、背包带"，生成后检查 |
